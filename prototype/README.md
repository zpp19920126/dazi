# 幼儿连连看（粉色童话风）— 单文件原型使用说明

交付物：`prototype/lianliankan-prototype.html`（单文件、零网络依赖）。本文档面向家长：如何打开玩、如何跑测试、真机验收清单与真人试玩记录模板。

## 如何打开 / 玩

1. **本机快速体验**：直接双击该 `.html` 文件，或在浏览器中以 `file://` 协议打开。
2. **放到手机上玩（推荐）**：把这个单独的 `.html` 文件发到手机（微信/网盘/AirDrop 均可），用系统浏览器打开——iOS 用 Safari，Android 用 Chrome；其他内核受限的内置浏览器不保证。
3. **竖屏游玩**：界面按竖屏设计，请保持手机竖持；游戏会自动尝试锁定竖屏。
4. 全部音效/语音/动画均在文件内，**断网可玩**，不需要任何服务器。

## 如何运行测试

在本仓库根目录（或任意位置）执行：

```bash
bash prototype/tools/run-tests.sh
```

脚本会先用 `tools/extract.mjs` 从 HTML 中抽出 engine/store 模块到 `prototype/.test/`，再运行 `node --test`。当前基线：**18/18 全绿**（engine 13 项 + store 5 项）。

## 真机验收清单（spec §9 手工清单，交付后由家长在真机执行）

- [ ] **iOS Safari**：Safari 打开后"添加到主屏幕"，从主屏图标启动无地址栏
- [ ] **iOS Safari**：全程竖屏、页面无缩放/无滚动跳动
- [ ] **iOS Safari**：9 关全部可通关（每关棋盘消尽、进入下一关）
- [ ] **iOS Safari**：语音（配对鼓励语）与音效正常播放
- [ ] **Android Chrome**：添加到桌面 + 竖屏无缩放 + 9 关通关 + 语音，同上四项
- [ ] **Android Chrome**：`navigator.vibrate` 生效；不支持则静默跳过、不报错
- [ ] **断网飞行模式**：重开页面全功能可玩（生成、消除、洗牌、提示、进度读写均正常，spec §10.4）
- [ ] **无痕/隐私模式**：游戏不崩溃；进度不保存（下次从零开始）但本局正常（spec §8 降级为内存态）

## 真人试玩口径（spec §9 真人验证 / §10 成功标准 1、2）

由家长给 3 岁孩子试玩约 10 分钟，只观察不手把手教，判定口径：

1. 孩子能否在 **≤2 分钟** 内开始主动点两下相同图案（自发配对）；
2. 全程有无因"消不掉/不理解规则"而**受挫弃玩**；
3. 结束后孩子是否**要求再来一局**。

## 已知小项（均不影响验收，APK 阶段处理）

- 教学（teach）遮罩期间棋盘不可点：属预期引导行为，不影响验收，APK 阶段处理。
